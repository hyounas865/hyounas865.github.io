Hello There!

As a Data Science and ML Engineer, I specialize in developing advanced machine learning models, focusing on computer vision projects. I excel in crafting efficient code for the ML pipeline, particularly in object detection and image classification. Rigorously assessing model performance with metrics like accuracy and precision ensures our solutions are effective and efficient.

In my role, I deploy ML models into production, ensuring seamless integration and scalability. I optimize inference speed and memory efficiency, adept at resolving performance bottlenecks to enhance system speed and resource utilization.

For my Final Year Project (FYP), I specialized in a web-based project for pneumonia detection in chest X-rays using Convolutional Neural Networks (CNNs). I leveraged advanced CNN architectures, including ResNet, VGG, Inception, and DenseNet, to achieve optimal diagnostic accuracy. This project enabled me to deepen my expertise in deep learning, particularly in medical imaging, and contribute to innovation in healthcare technology by delivering a reliable and efficient solution for pneumonia diagnosis.
